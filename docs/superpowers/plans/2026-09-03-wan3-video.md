# Wan 3.0 Video Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the official Alibaba Cloud Model Studio `wan3.0-video` option to Davis Video Studio without changing existing Seedance behavior.

**Architecture:** The browser continues to submit through `seedance-submit`, which becomes provider-aware. Wan requests are stored with `provider: dashscope`; `seedance-worker` submits and polls them through a focused shared Wan adapter, normalizes the result to the existing durable task/output pipeline, and preserves Google Drive backup behavior.

**Tech Stack:** Browser JavaScript, Supabase Edge Functions/Deno, Node test runner, Alibaba Cloud Model Studio asynchronous video API.

**Spec:** User-approved screenshots and chat requirements from 2026-09-03.

## Global Constraints

- Work only on `feature/wan3-video`; keep `backup/frontend-pre-wan3-20260903` unchanged.
- Preserve all existing Seedance options and request behavior.
- Use the verified DashScope endpoint with `DASHSCOPE_API_KEY`; prefer the Beijing workspace endpoint when optional `DASHSCOPE_WORKSPACE_ID` is configured, otherwise use the verified generic DashScope endpoint.
- Wan supports 480P, 720P, 1080P; ratios adaptive, 16:9, 4:3, 1:1, 3:4, 9:16; duration 2-30 seconds; optional audio.
- Never store the API key in Git, browser JavaScript, task payloads, or logs.
- Do not publish to `main` until tests and rendered-page verification pass.
